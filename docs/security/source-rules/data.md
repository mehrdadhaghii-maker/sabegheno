قوانین پاک‌سازی داده‌های حساس (Data) — PostgreSQL + Prisma

1. داده‌های حساس:
   - شماره موبایل
   - ایمیل
   - شماره کارت بانکی

2. زمان پاک‌سازی:
   - بعد از حذف اکانت توسط کاربر → داده‌ها فوراً حذف شوند
   - بعد از ۳۰ روز از درخواست حذف → حذف نهایی (Hard Delete)
   - در صورت غیرفعال بودن اکانت بیش از ۱۲ ماه → حذف خودکار

3. روش پاک‌سازی:
   - حذف نرم (Soft Delete): فیلد deletedAt تنظیم شود، داده در دیتابیس بماند
   - حذف سخت (Hard Delete): ردیف از دیتابیس حذف شود
   - برای کارت بانکی: هرگز ذخیره نشود! فقط توکن امن (از درگاه پرداخت) نگهداری شود

4. پیاده‌سازی پیشنهادی:
   - جدول User: فیلد deletedAt (تاریخ حذف)
   - جدول PaymentCard: فقط توکن + ۴ رقم آخر کارت (برای نمایش)
   - Cron Job روزانه: بررسی و حذف خودکار اکانت‌های منقضی

5. گزارش:
   - بعد از هر پاک‌سازی، گزارش تعداد رکوردهای حذف‌شده ثبت شود
