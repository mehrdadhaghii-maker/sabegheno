قوانین امنیت کلی (Security) — Node.js + Express + Prisma + React

1. احراز هویت:
   - رمز عبور: حداقل ۸ کاراکتر، شامل حروف بزرگ/کوچک، عدد و نماد
   - هش رمز: bcrypt با cost factor 12
   - احراز هویت دومرحله‌ای (2FA): برای ورودهای حساس (اختیاری)

2. مدیریت سشن:
   - توکن JWT با انقضای کوتاه + Refresh Token
   - ذخیره سشن‌ها در دیتابیس (PostgreSQL)
   - بستن سشن در صورت تغییر رمز عبور

3. حفاظت از API:
   - همه routeها با middleware احراز هویت محافظت شوند
   - Rate Limiting روی همه endpointها
   - Validation ورودی‌ها با zod یا joi
   - CORS فقط برای دامنه فرانت‌اند مجاز

4. امنیت دیتابیس:
   - Prisma با پارامترهای امن (بدون raw query خطرناک)
   - رمزنگاری داده‌های حساس (شماره موبایل، ایمیل) در دیتابیس
   - پشتیبان‌گیری منظم + رمزنگاری پشتیبان‌ها

5. امنیت فرانت‌اند:
   - React: بدون dangerouslySetInnerHTML غیرضروری
   - Tailwind: بدون استایل‌های inline خطرناک
   - Vite: build نهایی با minify و بدون source map در production

6. گزارش نهایی:
   - بعد از هر بررسی، گزارش کامل با وضعیت هر مورد ثبت شود
