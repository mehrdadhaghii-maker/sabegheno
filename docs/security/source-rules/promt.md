تو یک توسعه‌دهنده ارشد امنیت بک‌اند هستی. پروژه ما با این تکنولوژی‌ها ساخته شده و در حال اجراست:

- بک‌اند: Node.js + Express + Prisma + PostgreSQL
- فرانت‌اند: React + Vite + Tailwind

می‌خوام ۴ مستند رسمی و حرفه‌ای برای پروژه‌ام بنویسی. هر مستند باید شامل: هدف، قوانین دقیق، روش پیاده‌سازی، و بخش گزارش‌گیری باشد. زبان مستندها فارسی است.

مستند ۱ — AUTH (احراز هویت):
- چک ورود و خروج کاربران
- قفل اکانت بعد از ۵ بار رمز اشتباه به مدت ۴۸ ساعت
- بستن سشن بعد از ۳۰ دقیقه بی‌فعالیتی
- بستن سشن قبلی با ورود جدید
- مدیریت سشن با JWT + Refresh Token

مستند ۲ — HACK (تست نفوذ و امنیت):
- بررسی و رفع SQL Injection (با Prisma)
- بررسی و رفع XSS (با React)
- بررسی و رفع CSRF
- بررسی Authentication Bypass
- فعال‌سازی Rate Limiting
- تنظیم Security Headers با helmet
- بررسی وابستگی‌ها با npm audit
- معرفی ابزارهای تست نفوذ (OWASP ZAP / Burp Suite)

مستند ۳ — DATA (پاک‌سازی داده‌های حساس):
- پاک‌سازی شماره موبایل، ایمیل و کارت بانکی
- حذف فوری بعد از درخواست کاربر
- حذف خودکار بعد از ۳۰ روز
- حذف خودکار اکانت‌های غیرفعال ۱۲ ماهه
- ذخیره توکن به جای شماره کارت بانکی
- Cron Job برای حذف خودکار

مستند ۴ — SECURITY (امنیت کلی سامانه):
- رمز عبور قوی (حداقل ۸ کاراکتر ترکیبی)
- هش رمز با bcrypt (cost factor 12)
- احراز هویت دومرحله‌ای (2FA)
- Validation ورودی‌ها با zod یا joi
- CORS محدود به دامنه‌های مجاز
- رمزنگاری داده‌های حساس در دیتابیس
- امنیت فرانت‌اند (بدون dangerouslySetInnerHTML غیرضروری)

در پایان، یک چک‌لیست نهایی با ستون «گزارش» برای هر ۴ بخش بنویس تا بعد از انجام هر مورد، نتیجه ثبت شود.
