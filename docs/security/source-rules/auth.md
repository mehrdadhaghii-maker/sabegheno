چقوانین احراز هویت (Auth) — سامانه Node.js + Express + Prisma

1. چک ورود (Login):
   - کاربر با ایمیل + رمز عبور وارد می‌شود
   - رمز عبور باید هش‌شده (bcrypt) در دیتابیس ذخیره شود
   - هرگز رمز عبور به صورت متن ساده ذخیره نشود

2. قفل اکانت (Account Lockout):
   - بعد از ۵ بار رمز اشتباه → اکانت قفل می‌شود
   - مدت قفل: ۴۸ ساعت
   - بعد از قفل، حتی با رمز درست هم ورود ممکن نیست
   - پیام خطا: «اکانت شما به دلیل تلاش‌های ناموفق مکرر به مدت ۴۸ ساعت قفل شده است»

3. بستن سشن (Session Management):
   - هر کاربر فقط یک سشن فعال دارد
   - ورود جدید → سشن قبلی بسته می‌شود
   - سشن بعد از ۳۰ دقیقه بی‌فعالیتی منقضی می‌شود
   - کاربر می‌تواند از پنل، سشن خود را به صورت دستی ببندد

4. پیاده‌سازی پیشنهادی:
   - توکن: JWT با انقضای کوتاه (۱۵ دقیقه) + Refresh Token
   - ذخیره سشن: در جدول Session در PostgreSQL
   - شمارش تلاش‌های ناموفق: در جدول LoginAttempt
   - قفل: فیلد lockedUntil در جدول User
