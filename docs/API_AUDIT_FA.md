# نتیجه بررسی APIهای api.ir

بررسی با Swagger رسمی `https://s.api.ir/swagger/v1/swagger.json` انجام شد. مسیرهای استفاده‌شده در پروژه وجود دارند و بدنه‌های اصلی با schema رسمی منطبق هستند.

| سرویس | مسیر | وضعیت |
|---|---|---|
| احراز موبایل/کد ملی | `/api/sw1/ShahkarPro` | منطبق؛ در production fail-closed شد |
| پیامک OTP | `/api/sw1/SmsOTP` | منطبق؛ template=1 برای کد ورود |
| احراز هویت شخص | `/api/sw1/PersonInfo` | منطبق؛ nationalCode و birthDate الزامی |
| تسهیلات فعال | `/api/sw1/ActiveLoans` | منطبق؛ پاسخ aggregate است |
| چک برگشتی | `/api/sw1/UnpaidChequePro` | منطبق؛ فقط چک‌های فعلی برگشتی را می‌دهد |

## اصلاحات اتصال

- timeout پانزده‌ثانیه‌ای و تشخیص خطای شبکه/timeout اضافه شد.
- پاسخ `success:false` همیشه خطا محسوب می‌شود.
- در production، نبودن یا شکست Shahkar اجازه ورود کاربر نمی‌دهد.
- اتصال موبایل به کد ملی موجود قابل تغییر نیست.
- داده‌های تسهیلات و چک برگشتی به‌عنوان aggregate/منبع محدود نمایش داده می‌شوند.

بدون `API_IR_KEY` واقعی، درخواست live به حساب شما ارسال نشده است؛ فقط مسیرها و schema رسمی بررسی شده‌اند.
