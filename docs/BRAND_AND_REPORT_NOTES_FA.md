# تغییرات هویت بصری و گزارش سابقه‌نو

## مرجع طراحی

نمونهٔ لاگین ارسالی، رنگ‌های سرمه‌ای و فیروزه‌ای، وضعیت موفقیت سبز، پس‌زمینهٔ خاکستری بسیار روشن، کارت سفید با گوشه‌های نرم و دکمهٔ اصلی فیروزه‌ای را به‌عنوان زبان بصری مرجع مشخص می‌کند. گزارش PDF اعتبارسنجی ایران نیز مبنای ساختار گزارش قرار گرفت، نه مبنای کپی‌کردن برند یا ادعای رسمی.

## رنگ‌های اصلی

| نقش | مقدار |
|---|---|
| سرمه‌ای برند | `#0B1F3A` |
| سرمه‌ای ثانویه | `#123B5D` |
| فیروزه‌ای اصلی | `#0FAF9E` |
| فیروزه‌ای تیره | `#087F76` |
| پس‌زمینهٔ mint | `#DDF7EE` |
| پس‌زمینهٔ صفحه | `#F5F7FA` |
| مرز کارت | `#DCE5EA` |
| نوار بخش گزارش | `#B9DDF5` |

این سیستم در tokenهای فرانت‌اند، CSS پنل ادمین، دکمه‌ها، جدول‌ها، نمودارها، وضعیت‌ها، فرم ورود و کارت‌های گزارش اعمال شده است. رنگ بنفش قبلی از primary stateهای پنل ادمین حذف شده است.

## ساختار گزارش جدید

گزارش اعتباری در صفحهٔ «تصویر اعتباری مشتری» اکنون با سربرگ رسمی، شناسه گزارش، وضعیت تولید، اطلاعات هویتی محافظت‌شده، امتیاز اعتباری، نوار ریسک، پیشنهاد تصمیم و جدول شاخص‌های مؤثر شروع می‌شود. بخش‌های قبلی مربوط به سلامت، روند، منابع، تسهیلات، چک و همپوشانی بعد از این بخش‌ها باقی مانده‌اند.

کد ملی خام در رابط کاربری و export نمایش داده نمی‌شود؛ سیستم همان الگوی امن قبلی، یعنی hash و شناسهٔ محافظت‌شده، را حفظ می‌کند. گزارش سابقه‌نو نیز با گزارش شرکت اعتبارسنجی ایران اشتباه گرفته نمی‌شود و متن رابط، «امتیاز/تصمیم سابقه‌نو» را از گزارش رسمی جدا نگه می‌دارد.
