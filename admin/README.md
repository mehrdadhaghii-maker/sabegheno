# سابقه‌نو — Frontend (کسب‌وکار / کاربر)

اپ React مصرف‌کننده‌ی سابقه‌نو — برای کسب‌وکارها (استعلام، ثبت گزارش، تاریخچه، سیاست) و کاربران عادی (مشاهده گزارش شخصی).

**پنل مدیریت سابقه‌نو جدا شده و تو پروژه‌ی `sabegheno-admin` هست** — عمداً، چون این پروژه قراره در آینده Android هم بشه و پنل ادمین ربطی به اون نداره. جزئیات دلیل جداسازی رو تو README همون پروژه بخونید.

## اجرا

```bash
cp .env.example .env
npm install
npm run dev
```
روی پورت **5173** بالا میاد.

## چی اینجاست

- ورود OTP (کسب‌وکار یا کاربر عادی)
- داشبورد، استعلام جدید، تصویر اعتباری مشتری
- ثبت گزارش کسب‌وکار (تعهد/تسویه/تأخیر/چک برگشتی/بدحسابی)
- تاریخچه‌ی استعلام‌های خودِ کسب‌وکار
- سیاست اعتباردهی
- مشاهده‌ی Providerها (فقط‌خواندنی — برای وصل‌کردن Provider به کسب‌وکار به پنل ادمین برید)
- گزارش شخصی کاربر عادی

## نکته‌ی توسعه‌ی آینده (Android)

`api.js` از `VITE_API_BASE_URL` استفاده می‌کنه، پس برای production فقط کافیه این مقدار رو به آدرس واقعی بک‌اند تغییر بدید. اگه بعداً خواستید این رو به یه اپ Android تبدیل کنید، دو مسیر معقوله:
1. **React Native** — منطق `api.js` و ساختار صفحات قابل استفاده‌ی مجدده، ولی کامپوننت‌های JSX (که فعلاً از `div`/`table` استفاده می‌کنن) باید بازنویسی بشن.
2. **Capacitor** (wrap همین اپ وب) — سریع‌تر ولی تجربه‌ی کاربری کاملاً Native نمی‌ده.

تصمیم بین این دو رو بسپارید برای وقتی که واقعاً به این مرحله رسیدید؛ الان زودتر از موعده.


## Fixed-version notes

Admin-only policy editing and provider administration are intentionally not shown in this business/user client. Configure `VITE_API_BASE_URL` for the backend URL before local testing.
